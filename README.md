- ✅ Diseño moderno y responsivo
- ✅ Bootstrap 5
- ✅ Colores personalizados (púrpura y rosa)
- ✅ Sección de productos con precios
- ✅ Cómo funciona en 3 pasos
- ✅ Testimonios de clientes
- ✅ Contacto con WhatsApp, Email e Instagram
- ✅ Navegación fija
- ✅ Animaciones suaves

## Personalización

### Colores
Los colores principales se pueden cambiar en el archivo `index.html`:

```css
:root {
    --primary-color: #6c63ff;    /* Púrpura */
    --secondary-color: #ff6b6b;  /* Rosa */
    --dark-color: #2d3436;       /* Oscuro */
    --light-color: #f8f9fa;      /* Claro */
}
```

### Contenido
- **Título**: Cambiar en la etiqueta `<title>`
- **Descripción**: Cambiar en la meta descripción
- **Productos**: Modificar las tarjetas de productos
- **Precios**: Actualizar los precios en los badges
- **Contacto**: Actualizar los enlaces de WhatsApp, Email e Instagram

## Activar GitHub Pages

1. Ve al repositorio en GitHub
2. Haz clic en **Settings**
3. En el menú lateral, ve a **Pages**
4. En **Source**, selecciona la rama `master`
5. Haz clic en **Save**
6. Espera unos minutos y tu página estará disponible
